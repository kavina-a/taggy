## Phase Goal

**As a** Colombo consumer, **I want to** search, filter, and browse the business directory entirely as a guest, signing up via phone OTP only when I'm ready, **so that** I can quickly decide where to eat, shop, or hire a local service without friction or a forced login.

<objective>
Lay the shared, one-time foundation both of this phase's independent verticals (search and phone-OTP accounts) build on: install the new npm/shadcn dependencies, extend `prisma/schema.prisma` with every new Phase 2 model/column in a single migration, and implement the pure OTP-hashing primitives.

Purpose: `prisma/schema.prisma` and `package.json` are single shared files — two plans editing either one in parallel would race. Consolidating every Phase 2 schema change and dependency install into one Wave 1 plan lets the two verticals (02-02 Search Engine, 02-03 Auth Core) build in parallel afterward with zero file contention. Output: New deps + shadcn primitives installed; `User`/`OtpChallenge` tables and `Business.searchable`/trigram index live in Postgres; OTP code generation/hashing proven correct in isolation.
</objective>
