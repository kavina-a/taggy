## Phase Goal

**As a** Colombo consumer, **I want to** search, filter, and browse the business directory entirely as a guest, signing up via phone OTP only when I'm ready, **so that** I can quickly decide where to eat, shop, or hire a local service without friction or a forced login.

<objective>
Ship the first real, end-to-end usable slice of search: a guest can search from a real search bar and land on a real `/search` results page showing ranked business cards — the thinnest viable slice per MVP task ordering, with filters/sort/map layered on afterward by 02-08.

Purpose: This is the plan where SRCH-01/02 become genuinely demonstrable to a user for the first time this phase. It deliberately does not yet include the filter sidebar/sheet, sort dropdown, or map (02-08) — those are additive refinements on top of this working core, not prerequisites for it.
Output: `/search?find_desc=...&find_loc=...` renders real ranked results; `GET /api/search` returns the same data as JSON; `components/directory/business-card.tsx` gains the optional search-context props UI-SPEC calls for, without breaking Phase 1's directory page.
</objective>
