## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-11 | Information Disclosure | scripts/fetch-seed-images.ts | medium | mitigate | API keys read from `process.env` only, never logged, never written into any committed file (`.env.example` documents the variable name only, never a real key value) |
| T-06-12 | Tampering | scripts/fetch-seed-images.ts downloaded images | low | mitigate | Every downloaded image is re-encoded through `sharp` (resize + re-compress to JPEG) before being written to disk — this normalizes format/strips any embedded metadata/malformed-file risk from the third-party response rather than writing the raw response bytes directly |
| T-06-13 | Denial of Service | Pexels/Pixabay API calls | low | accept | Script runs at most once per developer, fetching at most 160 images total against public free-tier APIs — not a request pattern that risks rate-limit abuse or requires retry/backoff hardening for this project's scale |
